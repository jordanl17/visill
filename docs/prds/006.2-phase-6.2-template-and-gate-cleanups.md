# Phase 6.2 - template and gate cleanups

Status: Proposed. Owner: jordan.lawrence@sanity.io. Date: 2026-05-27.

## Goal

Green every CI gate by closing the four defects the Phase 6 + 6.1 integration gates surfaced. Each one is a latent bug from an earlier phase, exposed only once the canonical template, the scaffolder smoke gate, and the vendored example actually exercised the downstream path end-to-end. ADR 0017 promised the vendored example would do exactly this work; Phase 6.2 pays the bill.

## Why this is a follow-up

Each defect was latent because no prior test exercised the real downstream path. Phase 5's `createBundleTests` only ran with non-empty literal arrays; Phase 4's `render.py` only ran against a fixture that colocated `schema.json` with the script; Phase 6's scaffolder template predated ADR 0024; Phase 6's vendored-example CI job ran a build target that does not produce the zip the same job asserts. The integration gate caught all four, as designed.

Sites:

- `packages/visill-test/src/bundle.ts` - `createBundleTests` empty inner describe.
- `packages/create-visill/template/skill-src/scripts/render.py` - `SCHEMA_PATH` reads from the script's own directory, not from `assets/`.
- `packages/create-visill/template/tests/` and `packages/create-visill/template-dev/tests/` - plural directory violates ADR 0024.
- `examples/decision-tree/package.json` `build` script - `vite build` does not produce `decision-tree.zip`, but the CI job asserts the zip exists.

## Scope

In:

- The four defects above. Each fix lands in the package that owns the bug.
- Template-side application of ADR 0024 (the scaffolder shipped non-conformant in Phase 6 because Phase 6.1 only migrated workspace packages).
- One follow-up doc commit if the README needs to reflect the new single-command build.

Out:

- New feature work.
- Publish prep (Phase 7).
- Additional vendored examples.
- Eval CLI rewrites or description optimiser.
- Any SDK API change beyond the `createBundleTests` empty-suite guard.

## Deliverables

1. **`createBundleTests` skips the empty-literals suite.** `packages/visill-test/src/bundle.ts` adds an explicit `if (literals.length > 0)` guard around the `describe('critical string literals survive JS minification', ...)` block. When no literals are configured, the inner suite does not declare. Test coverage in `packages/visill-test/test/bundle.test.ts` adds a case asserting that a `createBundleTests` call without `criticalLiterals` produces a passing run with zero suite-empty failures. Ties to the `scaffolder-smoke` gate going green: a freshly scaffolded skill calls `createBundleTests` without literals.

2. **`render.py` reads `schema.json` from `assets/`.** Either the canonical `render.py` resolves `SCHEMA_PATH` against `HERE.parent / 'assets' / 'schema.json'`, or the `assembleSkill` plugin places `schema.json` next to `scripts/render.py`. Investigate both shapes before committing to one (see Risks). Whichever lands, the assembled skill must run `python3 scripts/render.py` end-to-end. Touches `packages/create-visill/template/skill-src/scripts/render.py` and possibly `packages/visill-build/src/assemble-skill.ts`. Ties to scaffolder smoke gate and vendored-example gate going green: both invoke `render.py` against the assembled layout.

3. **Scaffolder template moves `tests/` to `test/` per ADR 0024.** Rename `packages/create-visill/template/tests/` to `test/`. Rename `packages/create-visill/template-dev/tests/` to `test/`. Update the scaffolded `vitest.config.ts` `include` glob from `tests/**` to `test/**`. Refresh any scaffolder snapshot or fixture that asserts the directory name. Update the template `README.md` if it references the layout. Ties to: no `tests/` directory under `packages/create-visill/template/` or `template-dev/`; every newly scaffolded skill conforms to ADR 0024 from its first commit.

4. **`vite build` produces the skill zip.** `examples/decision-tree/package.json` `build` script chains zip production so a single `pnpm --filter=./examples/decision-tree build` produces `examples/decision-tree/skill/decision-tree.zip`. Preferred shape: `build: 'vite build && pnpm build:zip'` (single command, single contract). The same shape lands in `packages/create-visill/template/package.json` so scaffolded skills behave identically. Ties to the `vendored-example` CI gate going green.

## Lift map

| Fix | Source-of-truth pattern |
|---|---|
| `createBundleTests` empty-literals guard | Explicit `if (literals.length > 0)` around the inner `describe`. Vitest fails empty `describe` blocks; the conventional handling is to not declare them. |
| `render.py` path resolution | Actual assembled-skill layout produced by `assembleSkill` (assets/ siblings scripts/). Source of truth is the plugin's output tree, captured by the scaffolder smoke gate. |
| `tests/` to `test/` rename | ADR 0024. Mirrors the Phase 6.1 migrations in `visill` and `create-visill`. |
| `vite build` produces the zip | Conventional `build && build:zip` chain; same pattern already used in the three upstream skill repos. Consumer contract: `pnpm build` produces a ready-to-publish zip. |

## Success criteria

- A freshly scaffolded skill runs `pnpm build && pnpm test` clean on a clean machine.
- `pnpm prettier --check .` clean across the workspace.
- `vendored-example` CI gate green: `decision-tree.zip` exists after `pnpm --filter=./examples/decision-tree build`, with size within the committed baseline.
- `scaffolder-smoke` CI gate green: scaffolds, installs, builds, tests, asserts the zip.
- No `tests/` directory under `packages/create-visill/template/` or `packages/create-visill/template-dev/`.
- `createBundleTests` called without `criticalLiterals` produces a passing run.
- `python3 scripts/render.py` succeeds against the assembled skill layout.

## Test plan

- New `bundle.test.ts` case for the empty-literals path.

## Risks + mitigations

- **`render.py` fix lives on the wrong side.** The path mismatch could be fixed in either `render.py` (look one directory up) or `assembleSkill` (place `schema.json` adjacent to `render.py`). Investigate both before committing. Lean: fix in `render.py`, since the canonical skill-zip layout has `assets/` and `scripts/` as siblings, and that layout is observable to humans inspecting the published zip.
- **Zip-chain changes scaffolded `pnpm build` behaviour.** Every scaffolded skill now produces a zip on `pnpm build`, not just on `pnpm build:zip`. Document this in the template `README.md` so authors know `pnpm build` is the single delivery command.
- **Empty-suite guard masks real misconfigurations.** A `createBundleTests` call with `criticalLiterals: []` (deliberately empty) is indistinguishable from a missing field. Mitigation: guard on `length > 0` with an inline comment explaining the contract, and add the test case so future regressions surface. Do not use `describe.skip` - that emits a noisy skipped line that masks legitimate misconfiguration.
- **Snapshot churn from the `tests/` rename.** Any scaffolder snapshot asserting the directory name will diff. Mitigation: refresh snapshots in the same commit as the rename so blame is clean.

## Open questions

None blocking. The `render.py` vs `assembleSkill` fix-shape decision is in scope for the implementation wave and resolves on inspection of the assembled output.
